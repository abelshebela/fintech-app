# fintech-app
A lightweight Node.js fintech demo app containerized with Docker. It demonstrates best practices for building, running, and managing containerized applications, including Redis integration, port mapping, and avoiding common pitfalls like hardcoding secrets or using latest blindly.


# Fintech App (Containerized)

## 🚀 Overview
This project is a **mini fintech system** built with Node.js and Docker.  
It showcases containerization best practices and includes optional Redis integration.
